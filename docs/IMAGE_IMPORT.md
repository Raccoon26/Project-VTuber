# DEV-02 image input contract

Original Source is the exact selected byte sequence, stored at sources/<sha256>.<png|psd>. Source and original external file are never encoded, resized, color-converted or flattened. Preview Representation is a separately encoded RGBA8 sRGB PNG, at most 1024 pixels on either axis; nearest sampling is disclosed. Derived Working Data uses RGBA16 samples. Generated Data and User-Approved Changes are future independent artifacts, never replacements for Original Source.

The versioned inspection DTO binds parser identity, source hash, original dimensions/depth/mode, ICC hash/length, PSD byte ranges and layer records to a derived preview. It contains no original user pathname. This is reproducible derived data; the immutable original is authoritative. A bounded single-entry process cache holds at most 8MiB and is used only after the source hash is reverified. No persistent derived cache is a second source of truth.

Limits: input64MiB, canvas40M pixels, decoded PNG/PSD channel buffer160MiB, RGBA16 working buffer320MiB, PNG decoder192MiB, ICC4MiB, PSD1024 layer records,16 channels,64 group levels,4096 resource records. RGBA16 working allocation has its own320MiB ceiling; this preserves the original40M canvas range for8-bit PNG. 16-bit inputs may hit the independent decoded-channel limit first. Existing v1 sources remain readable even if the new preview budget refuses them. No implicit downscale to bypass the import budget. CPU path only, no GPU model or service.

Input is identified by signature. Windows input handles share read only, preventing cooperative writers/deletion during capture; size and modified time are checked before/after. Every ancestor/leaf is checked for reparse points. These are not an adversarial same-user handle-relative sandbox. Cancellation is checked at read blocks, rows, records and immediately before revision commit. A cancelled import can leave an unreferenced immutable original; it never destroys an earlier revision. Cancellation after publication cannot undo a committed revision; refresh/open determines the result.

PNG support: grayscale/indexed1/2/4/8, grayscale8/16, grayscale-alpha8/16, RGB8/16, RGBA8/16 through png0.17.16 EXPAND without stripping16-bit samples. Palette/tRNS expansion is a working representation only. CRC/stream errors and APNG are rejected. Metadata/ICC is preserved in source bytes; extraction is limited to relevant color fields. PSD matrix is separate.

Validation: image_tests.rs and existing resilience tests; independent psd-tools1.26.0 synthetic fixtures are checked in under tests/fixtures/source. This reference dependency is a development tool installed only on E, not required at runtime or in CI. Native UI and measured performance evidence must be recorded before release; current release evidence is PROJECT_STATUS and TEST_RUNS.
